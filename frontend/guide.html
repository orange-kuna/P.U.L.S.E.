Direct runtime dependencies and test dependency are pinned in pyproject.toml / uv.lock. Other standard-library modules used include: csv for telemetry export; datetime for UTC and forecast bounds; json for preset files and JSON export; math for kinematics; pathlib for file paths; collections/ threading for the bounded cache; and io for streaming exports. HTML, CSS and browser JavaScript are native browser features. Google Fonts are an optional visual enhancement; system fallback fonts work without them.

API & local testing

The simulation API is documented interactively at /docs. The application exposes /api/health, /api/config, /api/simulate, /api/weather and /api/windows. JSON and telemetry CSV can be downloaded from the run page.
